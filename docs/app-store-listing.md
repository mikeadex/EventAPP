# App Store listing copy

Paste-ready text for App Store Connect. Field limits are enforced by the store;
the counts here were checked against them.

Scope note: the platform is **churches, ministries and community
organisations** — `OrgKind` is `CHURCH | MINISTRY | COMMUNITY`, and the event
categories run from services and prayer through to conferences, classes,
fundraisers and socials. Copy that says "church events" only is narrower than
the product.

## Name (30)

```
Ekklesia Events
```

## Subtitle (30)

```
Church & community events
```

Names both audiences and puts "church" — the term people actually search — in
an indexed field. Avoid "Marketplace": it implies buying, and nothing on the
platform is paid.

## Promotional text (170)

Changeable any time without submitting a build, so use it for whatever is
current.

```
Find services, conferences, youth nights, small groups and community events near you — and RSVP in seconds. Every event is free to browse and free to attend.
```

## Keywords (100)

Comma-separated, no spaces. Do not repeat words already in the name or
subtitle — Apple indexes those separately and repeating wastes the budget.

```
christian,faith,worship,prayer,youth,ministry,service,rsvp,tickets,local,groups,conference,charity
```

## Notes for Review

Not public. Reviewers go looking for the guideline 1.2 features on a
user-generated-content app, so say where they are rather than letting them
hunt.

```
Ekklesia lists free events run by churches, ministries and community organisations in the UK.

DEMO ACCOUNT
Please use the credentials in Test Information. That account owns a demo organisation with a published event, so both the attendee and the organiser side can be exercised from one login.

USER-GENERATED CONTENT (guideline 1.2)
- Report: the flag icon on any event page, and on any host's page.
- Block: on any host's page. Undo it in Settings > Blocked.
- Filtering: listings are screened for objectionable content on create and on update.
- Published contact: david@ekklesiaevents.com, shown at https://ekklesiaevents.com/support
Every report is reviewed by a moderator and acted on within 24 hours, as committed in our Terms.

ACCOUNT DELETION (guideline 5.1.1(v))
Settings > Delete account. Also available without the app at https://ekklesiaevents.com/delete-account

PAYMENTS
None. Every event is free. No payment is taken and no card details are collected anywhere in the app.

PUBLISHER
This app is published by Michael Adeleye on behalf of Ekklesia Events (David Taribo), who operates the service. Written authorisation is available on request.
```

## Screenshots — still to produce

Required: **6.9"** (iPhone 16 Pro Max) and **6.5"** (iPhone 11 Pro Max / XS Max).
Apple scales those down for smaller devices, so two sets covers the phone
listing. iPad shots are only needed if the app stays listed for iPad, which it
is — `supportsTablet` is `true`.

Suggested five, in this order, because the first two are what most people see:

1. The event feed — several real listings with cover images
2. An event page — venue, time, host, RSVP button
3. A ticket with its QR code
4. The organiser view — attendees, or the check-in scanner
5. Report and block, which doubles as evidence for guideline 1.2
